# Repository and Execution Rules

1. Live repository truth wins over prompts/checkpoints.
2. `TODO.md` is the sole mutable backlog/execution authority.
3. Execute dependency-ready canonical tasks only.
4. Inspect existing implementation before adding/replacing behavior.
5. Never discard unrelated/interrupted work.
6. One task is not complete until acceptance/evidence/DoD pass.
7. Update `TODO.md` after every completed or newly blocked task.
8. Stable planning docs describe truth; do not turn them into shadow task trackers.
9. Changes to product truth update affected contracts/tasks in the same logical change.
10. No AI-ExecutionKit integration until the dedicated next round authorizes it.
