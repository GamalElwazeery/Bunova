# Bunova Agent OS

Agent OS composes ExecutionKit lifecycle discipline with Bunova-native specialists. `.agents/manifest.json` is the machine-routable registry; root `AGENTS.md` remains the human/operator instruction authority.

Native roles cover product planning, domain architecture, Laravel/backend, Flutter/offline operations, integrations, platform/SaaS operations, premium UX, QA/audit and security/release. Native skills/rules/workflows/contracts are registered directly rather than copied into generic replacements.

Routing is deterministic and sequential. Audit/review roles are separate from implementation roles. Tag supplements select platform, Flutter/offline, integration, financial/time/stock, premium/UX, security, content, SEO and release context. Fallback context must preserve repository recon and task authority.

`registered == integrated` is forbidden: every registered resource must be reachable through a route/fallback/supplement or declared dependency, and representative implementation/review/audit/blocker routes must be dry-run validated before K00 acceptance.
