# Bunova SEO OS

SEO capability is STANDARD and intentionally narrow: it applies to Bunova-owned public commercial/acquisition pages (product, café archetypes, capabilities, pricing/plans, help/legal/contact/signup/trial pages when public). POS, Owner/Admin, Platform Admin, operational APIs and authenticated app surfaces are private/non-indexable. Menuza search behavior is a separate product boundary.

`executionkit.seo.json` is the machine contract. Public page families require explicit intent, index eligibility, canonical/robots/status/sitemap/internal-link/rendered-HTML/metadata/structured-data/localization/performance rules before release. Programmatic SEO is fail-closed and is not enabled merely because Bunova can generate tenants/branches.

SEO evidence never guarantees ranking/indexing/rich results. Repository validation is distinct from production crawl/search-console evidence.
