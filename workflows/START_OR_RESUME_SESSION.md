# Workflow: Start or Resume a Work Session

1. Inspect live branch/HEAD/recent commits/status.
2. Read `AGENTS.md`.
3. Read `TODO.md` state and current phase gate.
4. Inspect interrupted/partial implementation and evidence.
5. Select earliest dependency-ready eligible task.
6. Read all task-linked authorities/rules/skills.
7. State the concrete task outcome and risks internally before editing.
8. Execute only from repository truth; checkpoints are hints, not authority.

If no task is eligible, record blocker in canonical TODO rather than inventing work.
