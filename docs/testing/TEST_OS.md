# Bunova Test OS

Test OS is FULL. During M0 planning there is no product runtime to test, so absence of Laravel/Flutter suites is not a fabricated pass. As P01 creates code, targeted backend/Flutter/contract/static tests become task-level evidence and phase-boundary full CI becomes mandatory.

Risk suites cover money/tax/discount/refund, time rating, stock ledgers, stored value, fiscal idempotency, tenant/platform isolation, offline sync/replay/conflict, Menuza/provider/router integrations, UI states, RTL/accessibility/visual regression, migrations, security and release candidate behavior.

CI is manual self-hosted only, project label `project-bunova`, with no GitHub-hosted fallback and no push-triggered full-suite policy. Physical macOS/Windows/device evidence is separate from repository configuration.
