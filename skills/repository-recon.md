# Skill: Repository Reconnaissance

## Use when
Starting/resuming any Bunova work, especially after interruption or handoff.

## Procedure

1. Read current branch/HEAD and recent commits.
2. Inspect uncommitted/unpushed work where the environment permits.
3. Read `AGENTS.md` and the relevant section of `TODO.md`.
4. Inspect task-linked plans/contracts/rules before implementation.
5. Search existing code/schema/tests for the task's concepts; never assume absent behavior from filenames alone.
6. Identify interrupted/partial implementation and evidence.
7. Report conflicts between prompt/checkpoint and repository truth; repository wins.

## Output
A short execution context: selected canonical task, dependencies, existing implementation/evidence, authorities, risks and exact next action. Do not create a second backlog.
