# Workflow: Deep / Honest / Full Audit

1. Freeze assumptions: inspect live repo and current TODO.
2. Scope audit against canonical product/domain/phase authorities.
3. Inspect implementation, migrations/schema, APIs, tests, UI and runtime evidence.
4. Search for placeholders/demo/mock/TODO/FIXME/skips/dead code and duplicated engines.
5. Audit financial/time/stock/fiscal history and reconciliation.
6. Audit permissions/tenant/privacy/secrets.
7. Audit offline/replay/conflict/reconnect.
8. Audit all relevant UX states, responsiveness, Arabic/RTL/accessibility and design-system reuse.
9. Validate integrations under failure/retry/duplicate conditions.
10. Classify findings P0/P1/P2 and add canonical tasks with evidence/authority.
11. Do not count already-open canonical future work as a defect unless current implementation contradicts it.
