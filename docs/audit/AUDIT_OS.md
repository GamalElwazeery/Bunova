# Bunova Audit OS

Audit OS is FULL and independent from construction. It challenges current repository/runtime evidence; it does not define Premium Experience or own remediation state.

Mandatory boundaries: wave/phase where declared, K00 deep-integration audit, P01-P21 phase audits and final release audit. Dimensions include domain completeness, financial/fiscal/time/stock invariants, offline convergence, authorization/tenant isolation, integration idempotency, content/SEO regressions, premium UI/component reuse, Arabic/RTL/accessibility, performance, placeholders/demo debt and launch evidence.

Every executable finding is mapped into `TODO.md`; reports are evidence only. Audits must distinguish future planned work from present defects and must report unavailable evidence as NOT_RUN/UNVERIFIED rather than PASS.
